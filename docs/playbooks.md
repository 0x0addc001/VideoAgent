# VideoAgent Playbook

| 属性 | 内容 |
| --- | --- |
| 文档版本 | v1.0 |
| 更新日期 | 2026-11-04 |

Playbook 是可复用的创作方案。它把业务场景、叙事结构、默认制作参数和审核要求
组合成一个可直接进入创作的项目起点。

## 1. 通用结构

每个 Playbook 包含：

- 场景名称与目标用户
- 业务目标与核心信息
- 默认 Skill、Hook、风格、画幅、时长和审核模式
- 输入要求与可选参考素材
- 推荐叙事节拍
- 输出与交付形式
- 积分和模型能力约束
- 审核标准与降级策略

## 2. Product Ad

适用于新品发布、卖点验证和效果广告。

默认编排：

- Hook：效果实证
- 结构：Hook → 使用场景 → 价值证明 → 产品主视觉
- 画幅：9:16
- 时长：10 秒
- Skill：`video_agent/product_film`
- 审核：生成前确认

## 3. Creator Vlog

适用于个人叙事、生活方式和品牌幕后内容。

默认编排：

- Hook：视觉氛围
- 结构：进入情境 → 日常推进 → 情绪转折 → 个人收束
- 画幅：9:16
- 时长：10 秒
- Skill：`video_agent/creator_vlog`
- 审核：自动

## 4. Micro Drama

适用于短剧片段、剧情广告和社交平台悬念内容。

默认编排：

- Hook：叙事反转
- 结构：建立人物 → 激化冲突 → 悬念或反转
- 画幅：9:16
- 时长：10 秒
- Skill：`video_agent/short_drama`
- 审核：生成前确认

## 5. Music Video

适用于音乐宣发、艺人视觉和节奏型品牌内容。

默认编排：

- Hook：声音开场
- 结构：视觉母题 → 表演 → 节奏升级 → 回到母题
- 画幅：16:9
- 时长：10 秒
- Skill：`video_agent/music_video`
- 审核：生成前确认

## 6. Localize

适用于已有成片的跨市场改编。

默认编排：

- 保留原剪辑、节奏和产品事实
- 适配语言、声音、字幕和人物形象
- Skill：`video_agent/video_localization`
- 审核：生成前确认

## 7. Batch Test

适用于广告素材矩阵和 Hook 测试。

默认编排：

- 固定产品事实和视觉识别
- 变化 Hook、场景和表达方式
- 生成带标签的可比较版本
- Skill：`video_agent/batch_variants`
- 时长：5 秒

## 8. 运营规则

- Playbook 必须引用有效 Skill。
- 默认参数必须与创作框字段一致。
- 模型能力不足时先降级或要求用户调整，不静默切换。
- 版本变化需要同步 PRD、Arch 和 Test。
